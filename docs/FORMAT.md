# tin 노트 텍스트 양식 (Single Source of Truth)

스캔 정규화기(`lib/note-format.ts`), Gemini 프롬프트, 테스트 픽스처가 전부
이 문서를 기준으로 동작한다. **양식을 바꾸고 싶으면 이 문서를 먼저 고치고,
픽스처를 추가한 뒤 규칙을 수정한다.**

`(확인 필요)` 표시는 기존 노트에서 추정한 규칙 — 실제 취향과 다르면 이
문서만 고치면 된다.

## R1. 문단

- 문단 사이는 **빈 줄 1개**(`\n\n`).
- 빈 줄 2개 이상(= `\n` 3개 이상)은 **의도적 스킵**으로, 노트에서는 보존한다.
  단, 스캔 출력에서는 의도가 없으므로 빈 줄 1개로 축약한다.
- 줄 끝 공백은 없앤다. 문서 시작/끝의 빈 줄도 없앤다.

## R2. 대사 (소설)

- **독립 대사 문단**(줄이 여는 따옴표로 시작하고 닫는 따옴표로 끝남)은
  앞뒤로 빈 단락을 둔다 — 즉 자기 혼자 한 문단이 된다.

  ```
  그는 오래 침묵했다.

  “가지 마.”

  나는 대답하지 않았다.
  ```

- **지문 속 인용**(문장 중간에 등장하는 따옴표)은 절대 분리하지 않는다.

  ```
  그가 “가지 마”라고 말했을 때 나는 이미 문 앞이었다.
  ```

- 여는 따옴표: `“ " 「 『 ‘` / 닫는 따옴표: `” " 」 』 ’`
  닫는 따옴표 뒤에 문장부호(`.`, `?`, `!`, `…`)가 붙은 줄도 독립 대사로 본다.
- 연속된 독립 대사도 각각 한 문단씩. (확인 필요: 주고받는 짧은 대화를 붙여
  쓰고 싶다면 이 규칙을 완화할 것)

## R3. 따옴표

- **원문 그대로.** 곧은따옴표↔굽은따옴표 변환, 따옴표 추가/삭제를 하지
  않는다. OCR이 방향을 뒤집은 경우(휴리스틱 복구)만 예외.

## R4. 페이지 마커

- 표준형: `##### Np.` (예: `##### 256p.`) — 해시 5개 + 공백 + 숫자 + `p.`
- 허용 입력: `##### 256`, `##### 256p`, `##### 256쪽`, `#####256p.` 등
  → 전부 표준형으로 정규화한다. 전자책 등 페이지가 없으면 `##### -p.`.
- 마커는 단독 줄이며 **앞뒤로 빈 줄 1개**.

## R5. 부제목

- 형식: `#` 1~4개 + 공백 + 제목 (예: `### 어린 시절`). 해시 5개는 페이지
  마커 전용이므로 부제목에 쓰지 않는다.
- `##제목`처럼 공백이 빠진 실수는 부제목으로 **관용 해석**한다
  (정규화기는 공백을 넣어주고, 웹 렌더러도 공백 없이 해석한다).
- 부제목은 단독 줄이며 앞뒤로 빈 줄 1개. (웹 뷰의 실제 간격은 CSS 마진이
  소유한다 — 위 넓게, 아래 좁게.)

## R6. 볼드 (발췌 하이라이트)

- `**…**` 짝을 맞춘다. 문단에 `**`가 한 번만 나오는 실수(한쪽 누락)는
  문단 시작/끝에 짝을 보충해 복구한다.
- 볼드는 원문 인용이므로 내부 텍스트는 건드리지 않는다.

## R7. 줄 내 공백

- 연속 공백은 1개로.
- 문장부호(`.`, `,`, `!`, `?`) 앞의 공백은 없앤다. 말줄임표(`…`, `...`)는
  건드리지 않는다.
- 한글 사이에 낀 OCR성 공백 복구는 reflow(휴리스틱)와 AI의 몫 —
  결정론 정규화기는 확신할 수 없는 공백을 건드리지 않는다.
