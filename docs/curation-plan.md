# [상세 기획서] 'tin' 발췌 큐레이션 디자인 및 색상 시스템 (Color & Typography Layout)

## 1. 디자인 대원칙 (Design Principles)

* **The Print Aesthetics:** 웹 화면이지만, 잘 짜인 종이 잡지나 미술관 도록(Printed Catalog)을 보는 듯한 착각을 주어야 함. 스크롤 레이아웃 대신 화면에 딱 들어맞는 고정 비율 프레임 권장.
* **Extreme Contrast:** 서체 크기의 대비(아주 거대한 서체 vs 아주 미세한 서체)를 극단적으로 주어 시각적 긴장감 형성.
* **Low Saturation, High Weight:** 색상은 채도가 낮고 매트한 솔리드 컬러를 사용하되, 면의 덩어리감을 묵직하게 인쇄용 잉크처럼 표현.

---

## 2. 색상 시스템 (Color Palette & Extraction)

유저가 책을 등록하면, 배경색과 오브제색은 쌩뚱맞은 색이 아니라 **'책 표지 이미지'에서 추출한 컬러 아키텍처**를 기반으로 유기적으로 결정된다.

### ① 시스템 공통 베이스 컬러

* **Background (Light Mode / Default):** `#F4F4F2` (차가운 화이트가 아닌, 오래된 도록 종이 질감의 아주 연한 미색)
* **Background (Dark Mode):** `#121212` (매트한 철제 깡통 내부 느낌의 칠흑 같은 딥 차콜)
* **Typography / Grid Line:** `#1A1A1A` (완전한 블랙이 아닌 묵직한 먹색) 또는 `#E5E5E5` (다크모드용 실버 그레이)

### ② 책별 고유 키컬러 추출 및 적용 규칙 (Dynamic Palette)

1. **지배색(Dominant Color) 추출:** 책 표지 이미지에서 가장 넓은 면적의 색상을 추출하되, 웹 화면에 얹을 수 있도록 채도를 한 단계 낮춘(Tone-down) **매트 틴(Matte Tin) 컬러**로 보정. (예: 쨍한 옐로우 ➡️ 하라 켄야식 겨자색, 쨍한 핑크 ➡️ 인디 핑크).
2. **배경과 오브제의 반전 매칭:** * 해당 책의 단독 큐레이션 뷰 진입 시, 추출된 키컬러가 화면 전체 배경(`background-color`)으로 깔림.
* 중앙에 생성되는 AI 메타포 오브제는 배경색과 완벽히 대비되는 모노톤(`Black` or `White`) 혹은 표지에서 추출된 제2의 서브 포인트 컬러를 부여받음.

## 3. 발췌 큐레이션 레이아웃 템플릿 (Layout Typo System)

모든 발췌문은 데이터 길이와 책의 무드에 따라 Claude가 3가지 모더니즘 템플릿 중 하나로 자동 조판(`Auto-composition`)하도록 컴포넌트화한다.

### 템플릿 A. 스위스 펑크 타입 (Swiss Punk Style) - 숏 텍스트 전용

* **대상:** 발췌문이 한 두 문장으로 짧고 강렬할 때.
* **구조:**
* **배경:** 책 표지 추출 키컬러 솔리드 채움.
* **오브제:** AI 생성 미니멀 오브제가 우측 하단이나 좌측 상단에 과감하게 치우쳐 배치 (`Object-align: asymmetry`).
* **타이포그래피:** Gemini가 정한 핵심 키워드 1단어가 화면의 70%를 차지하는 거대한 가변 폰트(Variable Font)로 화면을 찢고 들어옴. 그 행간 사이에 유저의 발췌문 본문이 아주 작은 폰트(12px)로 정교하게 정렬되어 파묻히는 형태.



### 템플릿 B. 에밀 루더 그리드 타입 (The Grid Matrix) - 롱 텍스트 전용

* **대상:** 발췌문이 길고 문단이 나뉘어 있을 때.
* **구조:**
* **배경:** 기본 미색(`#F4F4F2`) 배경.
* **면 분할:** 화면을 얇은 실선(`0.5px`)을 이용해 엄격하게 4등분 분할.
* **배치:** * [1구역]: 거대한 페이지 번호 조판 (`p.148`을 120px 크기로 좌측 상단 배치).
* [2구역]: AI 생성 미니멀 오브제가 완벽한 정방형 누끼 형태로 안착.
* [3구역]: 발췌문 본문이 양끝 정렬(`text-align: justify`)되어 책 인쇄본처럼 정갈하게 조판.
* [4구역]: 책 제목과 저자명이 아주 건조하게 세로 쓰기 혹은 미세 폰트로 구석에 박힘.





### 템플릿 C. 옛날 영화 포스터 타입 (Classic Poster Cinema) - 시네마틱 무드

* **대상:** 문학, 에세이 등 감성적이고 서사적인 텍스트일 때.
* **구조:**
* **배경:** 딥 차콜 바탕에, 중앙에만 키컬러가 은은하게 도는 사각형 프레임 레이아웃.
* **오브제:** 프레임 한가운데에 AI 오브제가 스튜디오 조명을 받은 듯 묵직하게 배치.
* **타이포그래피:** 클래식한 세리프(Serif) 서체(예:Times New Roman 혹은 가변 세리프 체)를 혼용. 발췌문 전체를 화면 하단에 영화 자막(Subtitle)처럼 넓은 자간으로 배치하고, 상단에는 브랜드 로고인 `tin`과 `Sn` 기호가 영화 제작사 마크처럼 아주 클래식하게 조판 됨.

## 4. 클로드(Claude) 지시용 프롬프트 요약 (Instruction for Claude)

> "위 사양서에 맞추어 프론트엔드단에서 책 데이터(제목, 저자, 발췌문, 페이지, 키컬러값)를 주입받으면, 텍스트 길이에 따라 자동으로 **'템플릿 A, B, C' 중 최적의 레이아웃을 계산해 렌더링하는 큐레이션 카드 컴포넌트**를 작성해 줘. CSS Grid와 Flex를 엄격하게 쓰고, 텍스트가 그리드 영역 밖으로 절대 터지지 않도록 양끝 정렬 및 자간/행간 비율 최적화 코드를 포함해 줘."
